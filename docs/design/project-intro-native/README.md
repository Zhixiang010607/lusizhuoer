# 登录前项目介绍 · 原生预览

当前三个项目入口位于公司主页最后一页，点击后以原生 WXML、WXSS 和页面滚动事件打开对应的官网式介绍；员工登录保持为右上角独立入口。项目介绍不使用 WebView，也不引用旧 Web 客户端代码。

- 海洋之蕴：15D 精雕仪，分层护理、MFU／RF／DP。
- 魔法柔肤：13D 柔肤仪，清／促／建护理思路。
- 露思康辰：E 脉通，电／磁／热与六项体验细节。

三项介绍在 `miniprogram-app/miniprogram/pages/project-intro/` 独立分包中，三张完整主视觉随该分包加载，不把大图加入主包。原登录背景、密码登录、手机号快捷登录和修改密码入口保留。

## 交互

原生页面上下滚动，章节图解随进度展开、旋转或强调。三个章节可直接切换，手动关闭动效后文字仍可阅读。短屏和横屏改用普通文档流，避免固定动画场景挤出正文与按钮。系统减少动态效果的 CSS 偏好会将图解恢复静态。

2026-09-15 最新精简中，“体验须知”入口、折叠内容及相关页面状态已彻底删除。页尾只保留“下一个项目”和“返回公司主页”，两个入口合并为同一条横向轻量导航；额外品牌装饰标题和末段大留白一并移除，不再纵向堆叠大按钮与附加模块。公开正文仍排除医疗功效、安全保证、认证、价格和固定疗程等未经核实内容。

项目切换用 `redirectTo` 替换当前页。返回时优先回到公司主页，直接进入介绍页时重新打开公司主页；登录页的启动校验仍按现有会话规则处理，不放宽任何业务页权限。
