# 登录前项目介绍 · 原生预览

用户此前看到的是独立浏览器提案，因此微信开发者工具的登录页没有改变。本次将真实登录页接入三个项目入口，以原生 WXML、WXSS 和页面滚动事件实现官网式介绍，不使用 WebView，也不引用旧 Web 客户端代码。

- 海洋之蕴：15D 精雕仪，分层护理、MFU／RF／DP。
- 魔法柔肤：13D 柔肤仪，清／促／建护理思路。
- 露思康辰：E 脉通，电／磁／热与六项体验细节。

三项介绍在 `miniprogram-app/miniprogram/pages/project-intro/` 独立分包中。三张完整主视觉随该分包加载，登录入口以轻量原生图形呈现，不把大图加入主包。原登录背景、真实密码和微信手机号登录、修改密码入口保留。

## 交互

原生页面上下滚动，章节图解随进度展开、旋转或强调。三个章节可直接切换，手动关闭动效后文字仍可阅读。短屏和横屏改用普通文档流，避免固定动画场景挤出正文与按钮。系统减少动态效果的 CSS 偏好会将图解恢复静态。

“体验须知”依用户反馈改为页尾默认折叠入口，点击展开实际禁忌和注意事项。原先占据整块版面的体验前说明及正文反复出现的资料解释已移除。随后按用户要求统一删除“本页为概念介绍／图示不代表效果／不作效果保证”等泛化声明，以及图解下方类似的辅助说明。须知展开／收起后重新计算阅读进度，收起不会把用户跳到其他区域。

项目切换用 `redirectTo` 替换当前页。返回时优先回到原登录页，直接进入介绍页时重新打开登录页。隐藏登录页会使尚未完成的启动校验回调失效，防止它突然将正在阅读的用户送回首页；返回后仍按现有会话规则处理，不放宽任何业务页权限。

## 素材与文案

内容映射、取舍和图片生成方式见 [content-notes.md](content-notes.md)。三张图片都是护理概念艺术，不是实际设备图、医学解剖图或效果对比。主视觉由内置图像生成工具制作，压缩 JPEG 保存于小程序分包；图解以原生视图和 CSS 绘制，可随滚动调整。没有复制原始 PDF／PPTX、员工资料或客户数据入库。
