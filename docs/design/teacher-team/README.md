# 小组长交互样板

2026-11-06 的独立 HTML 设计样板，供查看布局和点击交互。所有姓名、号码、工单、照片、地图及统计均为隔离示例；没有 CloudBase SDK、生产请求、账号登录或持久化。刷新页面重置示例状态。

## 最终设计边界

- 正式实现沿用原老师工作台，只为有效组长新增一个“小组运营”入口。不得改造原首页、增加小组汇总卡，或更改本人客户、业务、办理、学习、打卡、日报流程。样板的个人区只是现有页面的信息结构示例，不是个人首页改版。
- 小组运营独立展示成员名单、打卡追踪、日报追踪、活跃预警、余次预警。只读查看当前分配成员；不授予总部管理／审核，不开放其他老师、组长、门店或总部资料。
- 打卡追踪沿用总部布局：年月日选择、四类状态、姓名／电话／上下班时间／详情／时长，以及照片与位置详情。表格仅在自身区域横向滚动，日期不换行；iPad 详情地址与照片各占一半。
- 总部从基本资料档案卡设置／取消组长；设置后出现“人员管理”。模糊搜索普通老师添加、移除，每人仅归一个组长；其他组长不进入候选，已属于别组的老师不可直接添加。
- 取消组长释放全部成员，重新设置不恢复旧成员。普通老师与组长的个人工作台正文保持相同，只增加／移除小组入口。
- 电脑模式仅用于总部管理样板。老师和组长仍仅在小程序使用，不开放老师网页登录。

## 运行

只服务此目录，避免暴露仓库及私人维护目录：

```sh
python3 -m http.server 4189 --bind 127.0.0.1 --directory /Users/leemac/Documents/Lusizhuoer/docs/design/teacher-team
```

可直接打开 `index.html`，或访问本地服务器：

- `/?scene=basic&device=phone`：总部设置组长
- `/?scene=personnel&device=phone`：总部人员管理，初始三位成员
- `/?scene=personnel&device=ipad`：iPad 总部人员管理
- `/?scene=personnel&device=desktop`：电脑总部人员管理
- `/?scene=leader&device=phone`：原老师工作台结构示例，只有一个新增入口
- `/?scene=leader&device=phone&view=operations`：独立小组运营页面
- `/?scene=leader&device=phone&view=attendance`：总部同款打卡追踪

仅首次加载人员管理／组长示例时自动准备三位成员。页面内切换设备或场景不会恢复被移除的成员；只有“载入 3 位成员的样例”明确重置状态。与本功能无关的原老师流程以短提示说明，不在样板里模拟真实办理、改密码、封存或发布。

## 核对与状态

浏览器实点核对了设置、取消后清空、重新设置仍为空、姓名模糊搜索、十条候选分页／跳转、添加后禁用重复添加、别组成员不可添加、成员只读主页，以及打卡详情。撤销前后个人工作台正文读取比对相同；新增入口消失。

手机 320／390、iPad 834、电脑总部 1180 CSS 像素内容宽度核对：表格以外无越出设备边框的元素。截图保存在 `previews/`，均为样板浏览器实际渲染。
