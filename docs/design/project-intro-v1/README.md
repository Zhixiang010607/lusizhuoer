# 登录页项目介绍 · 第一版预览

用户希望在小程序登录页看到三个项目入口，点开后以官网式整页滚动介绍项目，并重新绘制图解、增加动效。本目录保留最初的可交互提案。后续用户明确要求接入实际微信开发者工具，并补充海洋之蕴资料，原生实现和当前状态见 [原生介绍记录](../project-intro-native/README.md)。

## 范围与状态

- 登录页下方三个紧凑入口；魔法柔肤与露思康辰各有一套完整滚动章节，支持章节跳转、相互切换、阅读进度、返回登录。
- 沿用暖象牙、香槟金与深咖色，复用现有品牌图的派生预览资产。两幅主视觉由内置图像生成工具原创；图解采用独立矢量绘制，随滚动展开／旋转／强调。
- 主视觉仅为概念艺术；海洋之蕴只展示待补充介绍的占位。文案提炼、PDF 页码与未采用的功效表述见 [内容记录](content-notes.md)，生成提示词见 [art-prompts.json](art-prompts.json)。
- **这是浏览器中的小程序界面提案，不是已接入的小程序页面。** 登录输入只读，无手机号、密码、人脸或业务数据采集；没有认证请求、业务 API、数据库读写或埋点。
- 首轮提案提交只涉及本设计目录和 `PROJECT_CONTEXT.md`，当时未改小程序运行代码、旧 Web 客户端、云函数或 SQL，也未进行部署。后续原生接入已发生，当前状态以原生介绍记录为准。
- 后续已另行使用原生 WXML／WXSS 实现；本目录的 HTML 或浏览器 API 未导入小程序运行目录。此处海洋之蕴占位和大块体验前说明属于旧提案，已被后续完整介绍和折叠须知取代。

## 文件

- `preview.template.html`：可修改的界面、文案、矢量图解与交互，图片用构建占位标记。
- `build-preview.cjs`：将当前目录的三幅图片内嵌为自包含预览片段。只依赖 Node 内置模块，无第三方安装步骤。
- `assets/`：两幅新主视觉与现有品牌图的压缩派生副本。原始 PDF 和用户私人素材不入库。
- `screenshots/`：浏览器实际渲染截图，**不是微信真机截图**。

在仓库根目录运行：

```sh
node docs/design/project-intro-v1/build-preview.cjs tmp/project-intro-preview.html
```

输出是供交互预览容器读取的 HTML 片段，不应放到旧 Web 根目录作为生产页面。内置预览容器负责加载 Lucide 图标；缺少设计调整工具时，普通项目切换与滚动仍可运行。

## 验证

对浏览器实际渲染进行窄屏、内容溢出、图片加载、项目进入／返回、三章切换、项目互跳与关闭动效检查；验证结果与边界在本轮完成后记录于 [validation.md](validation.md)。本轮没有修改业务实现，因此没有把过去的 314 项业务测试结果冒充本预览的微信验收。

滚动主视觉与图解由滚动位置驱动，不设置自动循环或强制等待页。系统开启减少动态效果时使用静态图解，章节文字仍可访问；页面也提供手动关闭动态效果的按钮。
