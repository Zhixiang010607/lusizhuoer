# 小程序公司主页与独立登录验证

日期：2026-09-15

## 需求落点

- 小程序首个页面为原生 `pages/company-intro/index`；打开小程序直接看到公司主页，不再经过公司介绍卡片。
- 公司主页使用六个原生竖向全屏分页；每次上滑完整进入下一页，停稳时只显示当前一页，不让上下两页跨页露出。
- 六页顺序为“首屏 → 我们是谁 → 品牌理念／品牌愿景 → 我们在做的事 → 与谁同行 → 项目延伸”，先说明公司身份与坚持，再承接具体行动、服务规模和项目入口。“与谁同行”使用用户确认的 `100+` 服务门店和 `10000+` 累计服务顾客，不增加排名、行业领先等推导。
- 第一页将现有 v4 金色水滴／侧脸 LOGO 原图作为全屏背景，公司全称与品牌主张分别保持一行并沿同一中轴排布；首屏不再重复左上角品牌名，抽象圆环和“公司主页”四字装饰标签已经移除。首屏登录放在公司介绍文字下方，使用居中小型描边按钮，不与右上微信胶囊拥挤。
- 页面使用同色系连续渐变和顶部阅读进度；页码固定在底部左侧，上滑提示固定在底部右侧，不再用右侧圆点切断画面。每页停稳后，标题、正文和细项依次上移渐显；降低动态效果偏好下直接显示静态完整内容。
- 第二页起，右上角“登录”继续进入独立 `pages/login/index`；登录页可返回公司主页，并完整保留密码登录、手机号快捷登录和修改密码。
- “加盟合作”说明和两个乐总电话直接合并在“与谁同行”页，不使用模拟电话弹窗、展开收起层或额外跳页；原独立加盟咨询页因与这里重复已经删除，项目延伸顺延为第六页。
- 海洋之蕴、魔法柔肤、露思康辰只在公司主页页尾作为延伸入口，不替代公司介绍主体。
- 旧的“公司介绍主卡＋三个项目卡＋页内折叠内部登录”方案已经退役。
- 本轮只修改微信小程序和规则／验证文档；未修改 Web、云函数、数据库或线上业务数据。

## 合规表达

公司主页未使用“抗衰”“逆龄”“治愈”“疗效”“医学级”“医美赛道”“全国领先”“第一”“唯一”等医疗、绝对化或未经核实的宣传词。项目摘要使用“方向”“关注”“体验”等生活美容表达，不宣传疾病治疗、疼痛治疗、健康结果或保证性效果。

按用户决定，公司宣传正文不展示“内部数据协同”“不提供在线交易”等系统说明。上述内容可用于平台申诉材料解释业务边界，但不应成为面向浏览者的公司宣传文案。

## 功能与权限检查

- 公司页为静态公开页面，不导入登录、业务 API 或数据服务；这是技术权限边界，不在公司宣传正文中展开说明。
- 公司页项目跳转只接受 `ocean`、`skin`、`warmth` 三个固定键，不能拼接到后台路由。
- 加盟咨询只允许用户点击后拨打乐总的 `18179422788` 或 `18160789986`，其他传入号码不会调用系统拨号。
- “与谁同行”页直接显示上述两个固定号码；号码按钮只接受这两个固定值，不存在模拟选择弹层、展开状态或分页切换。
- 公司主页不会因本地已有会话自动跳进内部工作台；用户点击右上角登录后，独立登录页继续执行原有权威会话校验。
- 登录页隐藏或离开后，延迟完成的启动会话校验失效，不会把用户从公司／项目公开页抢回内部首页。
- 登录页顶部返回胶囊使用独立前景层、完整按钮触控区和按压反馈；无论公司页是否仍在路由栈中，均返回公开公司主页。
- 本轮没有修改总部、门店、老师角色权限、认证方式或后台接口。
- 公司主页进入主包后，将登录后才使用的门店详情与老师详情调整为普通分包，主包继续保留至少 200KB 的源码余量；页面路由、会话和全局样式契约不变。

## 布局与动态检查

- 手机：六个原生分页均为完整视窗高度并裁切相邻页。首屏使用 v4 LOGO 背景，公司全称与主张各占一行并居中，首屏左上角不重复品牌名；登录小按钮承接在正文下方，第二页起再固定到微信胶囊左侧。“与谁同行”的两组数字、加盟说明和两个联系方式使用同一组分隔线与浅色按钮直接排在正文中，不形成悬浮弹层。重点标题和长正文使用按语义设计的均衡分行，避免行末只剩一两个字。
- 平板：主体宽度和字号设置物理像素上限，保留留白与长文行宽，不把手机 `rpx` 页面整体放大。
- 动态：切页时原生分页动画负责整页移动；切换完成后当前页文字按五级延时上移渐显。顶部进度与底部页码精确对应当前页，右下提示只承担上滑引导，不阻塞任何点击。
- 兼容：短屏断点收紧字号、间距和列表行高；用户偏好减少动态效果时，所有正文直接完整显示。
