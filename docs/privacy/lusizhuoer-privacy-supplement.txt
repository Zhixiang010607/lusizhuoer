露思卓儿通小程序用户隐私保护指引补充说明

本补充说明与微信平台展示的《露思卓儿通小程序用户隐私保护指引》（以下简称“主指引”）共同说明本小程序的个人信息处理情况。开发者名称、联系方式、信息存储期限及更新、生效日期，以主指引对应栏目为准。本说明补充介绍具体业务场景、信息类别和第三方技术服务，不延长主指引声明的保存期限，也不扩大其声明的处理目的。

一、适用的人员与业务场景

本小程序供露思卓儿业务体系的总部、门店和老师使用，用于员工登录、客户建档、充值、退费、正常核销、体验核销、产品业务、业务审核、记录查询及统计。客户资料由办理人员在相应业务过程中录入。

小程序操作者与客户可能不是同一人。操作者对其设备上的手机号、拍照、蓝牙或相册权限进行授权，不代表客户已经同意处理其本人资料。办理人员应在处理客户信息前向客户说明实际用途，并取得适用的授权；涉及人脸信息时，还应履行针对客户本人的单独告知和同意要求。

二、员工账号信息

为进行员工身份验证、识别既有业务账号、管理权限和维护账号安全，系统处理员工姓名或联系人、手机号、账号标识、角色、所属门店及登录认证信息。

选择微信手机号登录时，通过操作者主动触发的微信授权获取手机号，用于识别其既有业务账号。使用密码登录或修改密码功能时，按对应认证流程处理输入的手机号、密码或验证码。业务权限由服务端根据已建立的账号关系确定。

三、客户资料及业务记录

系统处理客户姓名、生日、客户编号、所属门店、客户状态，以及服务项目、充值、退费、正常核销、体验核销和产品业务的次数、数量、余额、业务时间、办理人与业务归属，用于客户识别、业务办理、记录查询、审核及统计。

系统还处理办理人员录入的客户备注、业务留言及客户评价，用于记录服务相关事项和反馈。请仅填写与业务目的有关的内容，避免在自由输入区域填写无关的身份证号码、金融账户或其他个人敏感资料。

四、客户照片与人脸核验

客户建档时拍摄客户照片，提交至后端进行照片质量、活体等检查，并建立该客户对应的人脸档案。正常核销或体验核销时，拍摄现场客户照片，通过云端人脸服务与所选客户的人脸档案进行一对一比对，用于确认接受服务者与所选客户是否为同一人，减少错误核销。

涉及的信息包括客户照片、客户姓名及对应人员标识、人脸档案标识、供人脸服务处理的面部特征和核验结果。客户建档照片、核销现场照片及业务补充照片还用于相应客户和业务记录的留存与授权查询。老师账号的创建不采集老师人脸。

人脸信息属于敏感个人信息，泄露或不当使用可能影响个人身份安全及其他权益。客户照片和人脸信息会经互联网传输至腾讯云相关服务处理，并非仅保存在拍摄设备内。开发者应就具体处理目的、方式、保存期限、必要性和影响向客户单独告知，并履行相应同意义务。

如客户对人脸信息处理有疑问，希望撤回同意、申请删除，或不同意采用人脸方式核验，可通过主指引中的联系方式向开发者提出，要求依法处理相关个人信息及核实可提供的其他业务验证安排。本说明本身不作为客户已经作出单独同意的证明。

五、图片、摄像头、蓝牙及相册权限

1. 图片与摄像头
在操作者主动拍照、选择图片或扫码时，用于客户建档拍照、核销拍照、上传业务补充照片、总部上传项目凭证背景，或扫描美容设备二维码。当前上述图片上传功能仅处理图片，不上传视频或录音。

2. 蓝牙
在设备核销授权流程中，使用蓝牙发现、连接现场美容设备，并处理设备标识、设备序列号、连接及工作状态，用于核对设备身份、发送当次服务授权和接收设备工作状态。

3. 相册写入
在操作者主动点击保存时，将其有权查看的业务照片、工单凭证图片或项目凭证样例写入设备相册。相册写入功能不读取相册中的其他照片；主动选择图片上传是独立操作。

六、第三方 SDK 与云服务

1. 腾讯云云开发 TCB SDK
SDK 名称：腾讯云云开发 TCB SDK（CloudBase JavaScript SDK，含微信小程序适配组件）。
SDK 提供方：腾讯云计算（北京）有限责任公司。
使用目的：员工登录及身份认证、保持认证会话、与业务后端通信和调用云端服务。
相关信息：微信用户标识、账号认证及会话信息，以及服务通信所需的设备和系统信息、网络信息、IP 地址；具体处理情况与实际使用功能有关。业务功能提交的客户及工单资料按本说明相应章节处理。
官方隐私保护指引：https://privacy.qq.com/document/preview/6a26468b77fd499984e529357e4d72a9

2. 腾讯云后端技术服务
系统使用腾讯云提供身份认证、云函数、数据库和私有对象存储，并调用腾讯云人脸识别服务完成客户人脸建档及核验。人脸服务处理范围包括建档或核验所需的客户照片、姓名、人员标识、人脸档案及比对结果。相关服务按实际业务调用处理信息。
腾讯云隐私保护声明：https://cloud.tencent.com/document/api/301/11470

当前小程序代码未声明微信第三方插件。SDK、云端技术服务与小程序开发主体分别承担各自职责；腾讯云作为技术服务提供方，不等于本小程序的开发者主体。

七、信息访问、存储及对外提供

系统按总部、门店和老师的角色、客户关系及业务归属控制信息访问，服务端对读取和业务操作进行权限校验。客户照片采用私有存储。不同角色可读取和可修改的范围并不相同，不能仅凭取得某项资料的查看权限修改他人业务。

开发者对信息的保存期限按主指引“开发者对信息的存储”栏目执行。临时访问链接失效、设备授权到期或本地缓存失效，不表示云端照片、人脸档案或工单已被删除；客户或账号封存也不等同于删除历史记录。

开发者应按照具体信息的处理目的和适用要求，确定最短必要的保留安排，并落实到期处理。涉及受托技术服务、不同经营主体之间的信息提供或对外披露时，应按实际处理关系履行告知、合同及适用的同意义务。

业务人员保存、导出或转发客户资料时，应确保其具有相应业务权限和信息使用依据，并妥善保管导出文件。本小程序的导出功能不构成向无关人员公开客户信息的授权。

八、个人权利与联系渠道

员工及相关客户可通过主指引中列明的开发者联系方式，申请查阅、复制、更正、删除个人信息，提出撤回同意、限制处理或账号注销等请求。客户即使没有本小程序的员工账号，也可通过该联系渠道提出请求。

开发者应对申请人身份进行必要核验，并依法处理和答复。确因适用的法定保留要求等原因不能立即删除的，应向申请人说明相关情况并依法限制后续处理。撤回同意不影响撤回前基于同意进行的信息处理活动的效力。

微信提供的权限管理、已获取信息及删除通知入口，以用户设备和微信当前版本显示为准。关闭设备权限通常会影响对应功能，但不等于已向开发者提出删除全部历史资料的申请。

九、未成年人信息

如业务涉及不满十四周岁的客户，应向其父母或其他监护人履行相应告知、取得监护人同意并适用专门保护规则。不得将普通业务人员的权限授权或生日录入视为已经取得监护人同意。监护人可通过主指引中的开发者联系方式提出与其监护对象信息有关的请求。

十、说明的更新

本补充说明随主指引共同提供。如信息处理目的、类别、方式或服务方等重要事项发生变化，开发者应更新相应说明，并依法履行告知及适用的同意程序。
