## 实现边界

Web 与 Mini Program 使用各自的年龄展示模块，不跨客户端复制 UI 或平台接口。Web 明确的列表路由加载独立序号修饰器；业务办理页不加载它。管理目录的搜索／活跃／封存各自持有页码，原始名单和计数保留。

Mini Program 所有本轮结果表移除 `scroll-y`；手机 rpx 和 iPad 物理 px 分开扩展到十行。原生 iPad 实测发现一次错误的跨单位高度推算（十行被裁成四行），已修正并增加单元回归。Web 管理目录残留 260px 固定框也已移除。

共享后端仅增加 `customerPageSize` 可选参数到 `getStoreDashboard` 和 `getTeacherBusinessCustomers`；1—100 整数，缺省仍 20，新客户端显式请求 10。计数、权限、排序、归属和所有写入函数不变。
