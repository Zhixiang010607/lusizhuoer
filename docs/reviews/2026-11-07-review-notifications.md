# 总部审核提醒验收

最终交互按用户修订，只在小程序首页顶部“审核”菜单显示小红点；展开后显示充值、退费、核销、产品审核的待审工单数，零隐藏，99以上显示99+。不增加底部栏、不增加备注列；原审核弹窗申请／审核留言、工单和客户链接、十条分页均保留。产品购买审核的界面名称改为产品审核，内部类型和原工单路由保持兼容。

数量由 staffAccount v102 的总部专用只读 getPendingReviewCounts 在一个数据库快照内统计。角色在查询前验证，老师、门店和组长不能读取。产品赠送和已通过充值赠品不属于独立购买待审；历史作废、正常核销、体验核销不进入角标。服务端只增加 SELECT，不改原审核、余额、扣次和业务统计算法。

保留共享数据库套餐。腾讯云拒绝为共享 PostgreSQL 启用 Realtime，用户随后明确选择前台30秒刷新。本机审核成功立即强制读回数量和当前服务端页；返回首页、切回前台立即读取。后台或离开首页／审核页停止计时，迟到响应作废，并发读取串行合并。失败不显示伪造的零或继续展示过期红点。

本轮无业务 SQL、无消息表或触发器、无 SDK 升级；没有改生产工单或使用真实工单测试审核。平台启用尝试前，已通过完整备份门禁验证43张public表412行，无行数差异；该尝试被平台明确拒绝，独立回读仍无realtime schema，公开业务表仍43张。私有回执保留，不入Git。

验证：完整测试720项通过；隔离PostgreSQL待审口径10项通过，既有业务统计158项、封存退组50项继续通过。覆盖身份切换、前后台、失败重试、审核中旧响应、无并发、原工单／客户精确链接、筛选与当前页保留。微信隔离工程只替换会话与网络适配器，实际页面字节和哈希留存，禁止连接生产。原生模拟器已验证产品3条审核后立即变2条，返回首页总数125变124；原弹窗仍有申请留言。

发布状态另见同日部署回执；源码或此文档不等同已完成小程序上传。

原生尺寸验收完成：手机320／390／430；iPad768／834／1024竖屏及1024×768横屏，顶部红点不遮挡菜单，所有页面均无底部审核栏。834宽样例第一页10条、第二页10条，上一页／下一页可用；精确跳页和末页缩短沿用原实现并有回归测试。工单链接参数另有四类型运行测试。验收图见同名assets目录。
