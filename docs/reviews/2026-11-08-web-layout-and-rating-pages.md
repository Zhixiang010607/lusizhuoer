# 2026-11-08 Web 布局与评价分析双页验收

本轮同时修改根目录 Web 和明确要求同步的小程序评价分析，不修改云函数、SQL、业务写入或统计口径。发布结果由文末独立记录补充。

## 最终交互

- 外层仅一个“评价分析”，进入后切换独立评价查询／评价图表，两按钮各占一半。查询评分默认不选，必须至少选一项；图表页没有分数控件，按范围统计全部评分。小程序筛选控件手机两等列、iPad 四等列，查询按钮与末列等宽等高；总部／门店／组长原授权范围及组内＋自己、组长不能导出或打开客户／工单的限制保留。
- Web 查询补齐产品查询，使用既有只读接口读取购买与充值赠送，动态产品分类及封存标记、十条分页、页内编号、页码跳转、客户及原充值链接保留。购买详情只读。
- Web 工作区去除 1120px 上限，桌面外边距 24px、手机 12px。产品管理与其他管理按钮、说明、表格及分页对齐；导航只高亮当前页面／当前菜单组。
- Web 打卡四类结果二乘二，日报两类结果左右双栏；手机单栏。直接选年／月／日，各组十条完整显示，无表格内部纵向滚动。
- Web 导出真实 XLSX，移除活跃预警“计算起点”列，日期使用北京时间日期、不含时分秒；保留“从未核销”和数值类型，按中英文内容适配列宽。
- 官网电脑侧栏／标题改“服务体系”，去除侧栏末尾重复登录，保留首屏登录。桌面服务段落利用宽度，手机原六屏名称保留。登录页使用原品牌花纹渐隐与暖色表单、暖色自动填充及焦点，认证逻辑不变。
- Web 顶部“审核”小红点和四项队列角标复用总部专用 getPendingReviewCounts。成功审核立即服务器重读；其他账号前台 30 秒更新，重新可见／获得焦点立即更新，后台暂停。迟到读、账号切换、错误和并发均不伪造数量。不增加服务器推送、短信、数据库表或角色权限。原工单链接和审核状态机保留。

## 验证范围

使用 localhost 隔离 fixture 与独立微信开发者工具工程，仅合成数据，不连接生产数据写入。页面源码与生产控制器直接复用，fixture 身份替换仅存在 tests/fixtures 中，不发布。

- 732 项 Node 回归通过，JavaScript 语法及 git diff --check 通过。通知覆盖串行强刷、旧响应丢弃、前后台、身份切换、错误／缺失数量、30 秒定时与禁止角色。
- Web 20 条业务路由 × 9 个视口（320／390／430／768／834／1024／1280／1440／2874）完成 180 次几何检查；最终受影响 11 条路由在 390／834／1440 完成 33 次复查，无整页横向溢出。六个管理页面 × 三尺寸，所有可见按钮文本中心误差小于 1px 水平、2px 垂直。
- 原生模拟器实际检查手机 320／390／430，iPad 768／834／1024 竖屏及 1024 横屏。最终新增等宽规则复查 390 手机和 1024 iPad 横竖屏。十条结果编号和翻页、未选评分拦截、图表无评分选择器、75/100 覆盖率与分布分母已验收。
- Web 产品结果第二页 1—10，跳到第三页仅一行编号 1；动态封存产品选项、购买只读详情、充值赠送原链接已检查。日报 10 行容器 clientHeight=scrollHeight=736，3 行容器均为 186，无内部纵向滚动。
- 独立 openpyxl 读取生成的 XLSX：四列、日期跨 UTC 午夜正确换成北京日期、9 天为数值、列宽存在；自动化另覆盖长中文宽度和公式样式字符串不执行。
- 登录显示／隐藏、返回、修改密码 UI 已检查，未发送验证码或修改真实凭证。服务体系在 1280／1440 下三条段落均一行，无单字孤行。

证据位于 assets/2026-11-08-web-layout；截图均为合成验收数据。原生工具与浏览器模拟不能替代实体 iPhone/iPad 微信硬件验收。
