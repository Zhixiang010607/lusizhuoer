# 考勤选择与补录只读分类

## 范围与业务边界

- 小程序本人工作月历、总部老师考勤／日报：中文年份和月份独立直选，退休逐月／逐年步进按钮，未来月份仍由上海服务端日期限制。
- 本人月历、总部老师考勤详情、本人打卡记录：上班／下班按钮切换，一次只显示一份记录；不改变真正办理时的下一种打卡类型。照片／地图沿用既有手机上下、平板左右排版。
- 已通过补录本质是正常核销。修正老师客户活跃／封存列表漏计 SUPPLEMENT，以及活跃预警 normal-baseline 人数、标签与导出分类不一致。
- Web 普通查询与工单详情将 SUPPLEMENT/APPROVED 显示为正常核销，原始类型和审核状态仍保留，待审／驳回不提前转换。同步修改脚本版本及所有引用的缓存键。
- 云函数除公开版本号和两个只读函数外，与原 HEAD 字节一致。没有 SQL、生产数据回填、余额重算，未修改创建、提交、审核决策、扣次、BLE、客户人脸、照片或评价权限。
- 主页正常核销统计本已合并 NORMAL/SUPPLEMENT；体验继续独立。客户主档“累计核销”沿用既有总服务次数含体验的含义，没有擅自修改数据库口径。统计时间继续沿用提交时间，而非补录审核时间。
