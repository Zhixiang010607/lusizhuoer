# 总部老师主页页签验收

## 范围

总部老师详情新增首个“老师主页”页签，保留基本资料、项目配置、考勤日报。展示目标老师资料、体验额度、原式项目汇总及四类业务明细；每页十条、页内编号、上一页／下一页和跳转。手机分页分组，iPad 同行排布；表格仅横向滚动，高度按实际行数测量。

`faceRecognition v135` 新增总部专用只读 action，认证总部 UID 后解析目标老师，复用原老师业务归属、有效单据及分页 SQL。原老师 action 仍固定本人身份；总部读取不执行月度额度重置，不接受详情编号，不切换老师会话。不改核销创建、人脸、BLE、扣次、照片、审核决定。无 SQL 或生产数据库维护写入。

## 验证

- 全套串行回归 621 通过、0 失败，包括八项新权限／异步状态／分页／跳转测试。一次并行运行遇到未修改 BLE 测试的 INFO 超时；最终串行两次均通过，不隐瞒该时序波动。
- 离线合成数据，真实 teacher-detail 页面和新组件；19 个生产源文件 SHA-256 与测试项目一致。测试 API 拒绝业务写入，不读取生产账号。
- 原生微信开发者工具检查手机 320／390／430、iPad 768／834／1024 竖向及 1024 横向；核对四页签、额度居中、十行表格与分页。430 下一页显示第二页数据且序号重新从 1 开始；跳转、空资料、失败、身份不匹配及迟到响应有自动化覆盖，并非所有状态都做了每种尺寸人工检查。
- 截图见同名 assets 目录。1024 横向受屏幕高度限制需正常页面滚动，表格本身没有独立纵向滚动区。
- 灰度基础库 3.17.1 在重复切换设备时出现框架 clickCheckTask／迭代异常；重新编译后横向页面零错误，仍有基础库预加载及组件导入样式的选择器警告。本记录不宣称控制台全程零错误。
