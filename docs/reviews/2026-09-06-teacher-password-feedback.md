# 老师创建密码提示修复 · 2026-09-06

用户确认已经输入密码，但只看到笼统的“请完整填写”提示。原校验将姓名、手机号与密码合并为一个错误，不能说明是哪项不符合要求；源码没有在该校验分支清空密码，因此不能根据截图空白断言发生了自动清空。

现在分别提示缺少姓名、缺少手机号、手机号格式、缺少密码、密码长度、首位和字符类别。密码错误直接显示在输入框下方，例如只有大写字母与数字时，会提示从小写字母或特殊字符中再补充一类。校验失败和切换显隐均保留原始输入；修改出错项会移除旧提示，提交时恢复密码隐藏。

当前认证服务使用 CloudBase `CreateUser`。其[官方密码规则](https://cloud.tencent.com/document/product/876/127961)明确要求 8–32 位、不能以特殊字符开头、四种字符类别至少包含三种。英文字母或数字均可开头，特殊字符可以放在后面。文档没有解释这条限制的设计原因；本次保持既有验证规则，不修改认证接口或云函数。

验证：303 项仓库测试通过；新增运行测试覆盖具体错误提示、无效表单不调用服务／不建立待办、输入与显隐保留、各类合法组合原样提交。官方微信开发者工具以实际页面源码和隔离服务，在 390×753 视口验证了空姓名、空密码、长度不足、首位错误、类别不足及两次显隐；没有创建真实账号。截图仅包含合成示例，未保存用户提供的姓名、电话或密码。
