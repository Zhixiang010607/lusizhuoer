# 本人打卡页：上下班办理与记录统一切换

2026-11-01，Australia/Sydney。

## 修复

原页签只切换已有照片／地图，下方“本次办理”却独立按今日进度自动展开下一笔，导致上班完成后仍在底部显示下班流程。本次统一使用当前类型控制可见记录与办理区：

- 上班页只显示上班记录；已上班后不再出现下班定位／拍照办理区。
- 只有点击下班页，且当天已有上班、尚未下班，才显示下班办理；未上班显示一行提示，历史日期只读。
- 提交成功停留在所提交类型，回到页首方便查看记录／切换；不自动切到下一笔。
- 切换类型或日期清除未提交的定位、照片、留存同意、错误和权限重试状态，不自动发业务请求。读取／定位／提交中禁止切换，客户端拒绝隐藏类型、历史日期或类型不一致的提交。
- 从本人考勤月历点“办理下班打卡”会携带下班类型进入对应页签，不再误落上班记录。
- 按手机／平板界面技能补齐禁用页签配色，覆盖微信原生禁用颜色，保持文字可读、当前类型仍清楚。没有调整原图、地图及其横竖屏布局。
