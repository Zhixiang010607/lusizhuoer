# 2026-11-06 老师兼任小组长

本次保留总部、门店、老师三种身份。普通老师工作台仅增加由服务端资格控制的“小组运营”入口；总览、成员查看及运营查询在独立子页面内。成员页直接复用现有老师详情及工作台组件，仅开放老师主页、考勤日报两栏。小组总览沿用总部筛选、项目汇总、排名、十条分页和导出；名单与统计均以当前分配成员为范围，排名中的门店不提供主页链接。

活跃度、余次与评价分析统一使用“当前组员＋组长本人”的可信关联客户集合。评价页复用既有筛选、双饼图和十条分页，取消成员或组长即时收窄／拒绝，禁止借此打开客户、工单或导出。打卡、日报和小组总览的成员范围保持不变。

总部在基本资料档案卡设置／取消组长，人员管理页签按姓名模糊搜索普通老师，分配与移除各有独立十条分页。普通老师全局唯一归属，不能加入组长、本人或直接跨组转移。取消组长在一个事务释放全部成员并保留审计。组长只读，无成员配置、密码、封存、任免或审核权限。
