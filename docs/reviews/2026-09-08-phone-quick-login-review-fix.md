# 手机号快捷登录审核整改

平台审核指出，调用手机号快速验证组件的前置登录页使用“微信手机号登录”等元素，可能与腾讯官方入口混淆。用户接受修改指引并要求修改发布。

本轮将登录页次按钮固定为“手机号快捷登录”，并把同一授权链路中可显示给用户的加载、取消、额度、权限、授权码缺失、SDK 不支持及登录失败提示统一去除“微信”字样。按钮继续使用平台规定的 `open-type="getPhoneNumber"`，认证结果仍经 CloudBase SDK、UID 一致性检查和服务端账号／角色／状态回读；没有新增注册、改绑、权限或数据库行为。

登录页只有露思卓儿自有的金色水滴／侧脸品牌图形和“露思卓儿”文字，没有微信官方 Logo。内部函数名和平台事件名用于调用小程序能力，不作为页面文字显示。

验证结果：

- 324 项仓库测试全部通过。
- 登录页 WXML 不显示“微信”或 `WeChat` 字样，按钮文案为“手机号快捷登录”。
- 原生开发者工具重新编译并截取 552 × 1194 登录页，按钮完整居中，未越界，原配色和项目入口保持正常。
- 没有云函数、SQL、静态网页或数据库变更。

原生检查截图保存在被 Git 忽略的 `output/login-phone-quick-0.2.73.jpg`，不包含手机号、密码或业务数据。
