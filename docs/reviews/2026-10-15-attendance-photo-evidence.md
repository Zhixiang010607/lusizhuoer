# 2026-10-15 考勤现场照片与 iPad 双栏

## 实现范围

- 同一次考勤原图先通过既有质量、活体配置和老师本人 1:1 检测，再生成留存照片；不替换为建档头像，不改变客户人脸、正常／体验／补录核销、BLE 或扣次。
- 私有 JPEG 等比保留全图、长边最多 1280px、最多 512 KiB；右下角永久写入上班／下班类型和完整秒级北京时间，不写位置或第三方验证标志。字形为既有 OFL 字体的微型矢量子集，云端不依赖系统中文字体。
- 使用同一数据库时刻制作水印和绑定不可变打卡。私有上传后回读字节数与 SHA-256，成功后才插入。已有打卡幂等回读不换图；空写入返回独立确认，不确定时保留候选对象，不误删可能已经绑定的文件。
- 新打卡必须明确同意留存。鉴权以实时 UID／SQL 为准：总部及在职本人可读，门店与其他老师不可读。历史无照片如实返回 null。缓存命中仍重新鉴权，缓存损坏重新读取，账号切换和晚到响应不得串图。
- 小程序四个考勤详情入口使用独立原生组件；总部 Web 老师主页与追踪详情增加鉴权照片查看，不开放老师／门店 Web 登录。
- 用户本轮补充的 iPad 规则：每次打卡的地址／地图在左、照片在右，左右各半、按钮底边对齐。上班和下班分别一张卡。手机保持单列，照片完整等比，不使用 cover 裁脸。
