# 总部项目汇总与空状态修复 · 2026-09-06

用户提供的截图显示两个问题：三个项目和合计下方残留大片空白；项目读取错误、排名空结果挤在表格首列且居中。本次修复小程序总部首页，保留原配色、查询口径和分页数量。

原汇总滚动容器按 `76 + 行数 × 94rpx` 估算高度，实际表头和内容行已经更紧凑，因此行数越多，底部空白越大。普通提示节点放在 CSS 表格内部，又被布局为首列的匿名单元格。

现在项目汇总由独立原生组件按真实渲染高度收合，长名称靠左完整换行，次数与单位保持同字号、同一行。加载、空结果和错误均独立占满内容宽度；错误状态提供重新读取，不再显示未确认的零项目或零合计。合计单独读取失败时保留已确认的项目行并提示重读。完整排名无记录时显示全宽提示，隐藏无效分页和跳页控件。
