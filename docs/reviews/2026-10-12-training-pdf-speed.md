# 培训 PDF 流程精简

## 范围与证据

用户反馈约 285 KB 上传、阅读均耗时接近一分钟。源码确认存在可去除的串行请求，但没有这次真机请求的完整耗时轨迹，不能声称已经确定该一分钟唯一根因。

- 上传文件读取和申请签名改为并行，失败仍回收本次随机对象引用。
- 发布检查合并为一次八字节 Range；Content-Range 校验真实总长度，Content-Type 和 PDF magic 均保留。
- PUT 回执不确定先按原请求恢复，避免完整对象被重复传输；403 等明确拒绝不再自动重复耗时。
- 暂时读取失败不删除完整上传对象，原请求可继续确认。
- 发布响应直接更新当前列表，不再把完整列表刷新放在完成路径中。
- 缓存命中仍回读当前 UID/账号状态和发布状态，但不请求存储签名。缓存版本、实际文件存在和长度继续验证。
- 第一次阅读在字节验证后直接打开原生临时 PDF，后台串行复制私有缓存；不再等待缓存复制才打开。
- 总部刚上传的文件也复用本地完整字节。无下载、保存或转发入口，没有公开桶。
- 仅检查文件大小时使用原生 stat，不再重复计算整份 PDF 的文件摘要；旧运行环境缺少该能力时保持原兼容路径。接口行为依据[腾讯云文件接口文档](https://www.tencentcloud.com/document/product/1219/68038)，真实大小与字节校验不取消。

云函数 v95 新增兼容可选参数 authorizeOnly；未传参数的网页版、旧小程序保持签名响应兼容。无 SQL、数据库迁移或生产资料增删。正常、体验、补录核销、人脸、BLE、照片和扣次实现未改。

## 字号只读检查

使用手机 UI skill 检查全部已注册页面、公共样式及组件的手机字号声明；这不是逐页真机视觉验收，本轮未改字号。

| 页面 | 需复核的小字号区域 | 源码字号 |
| --- | --- | --- |
| 客户主页 | 项目/产品汇总、业务记录表、页签、分页 | 21 / 22 / 18 rpx |
| 总部老师主页 | 项目额度表头、数据、删除、流水次级信息 | 18–22 / 17 rpx |
| 工作月历、老师主页月历 | 星期、图例、日期、翻月按钮、未入职标签 | 14–20 rpx |
| 培训学习 | 阅读/删除操作、文件日期大小、失败信息 | 19–22 rpx |
| 门店创建 | 字段标签、输入文字、主操作 | 21–23 rpx |
| 产品购买详情 | 字段标签、字段值 | 19 / 23 rpx |
| 客户选择组件 | 当前客户、同名候选、确认前信息 | 22–23 rpx |

充值/核销查询、审核、客户查询、预警结果和日报/考勤追踪的主要表格大多已有 24 rpx；首页存在旧小字号声明，但后续更具体的选择器覆盖为 24 rpx，不能把所有搜索命中都当作最终显示字号。卡片标题一般 29 rpx，不建议与次级辅助文字一起机械放大。后续实际修改必须另按手机多宽度、平板独立断点和核销回归验证。
