# 老师精确客户查询

老师总览新增“客户查询”。门店直接复用客户建立的 store-search，客户姓名必须手动完整输入；不预查、不提供姓名建议、不支持客户姓名模糊匹配。结果沿用客户查询的字段，生日显示为年龄，每页10条，含页内序号、前后翻页和页码跳转；表格只作横向滑动。

点击姓名复用现有完整客户主页。服务端按当前在职账号、在职门店、客户完整姓名与客户编号重新校验每次读取。非本人客户的备注、留言、五类业务历史、工单与原有照片可读；备注和留言写权仍由原创建／已通过可信业务关系独立判定。客户查询不产生业务关系或归属。工单返回客户主页时保留只读查询上下文。

照片的查询上下文只进入清单、原图及原图回退读取。上传、替换、取消仍使用原提交人和24小时规则；查询路径不归一化修改客户照片引用。照片原图继续沿用既有 VIEW_ORIGINAL 审计。评价只读例外只在 getForStaff，签发评价二维码权限不变。总部、门店及旧老师本人入口兼容；不改变业务创建、审核、扣次、BLE、余额或统计口径。

验证：

- 隔离 PGlite：209项检查、202条真实只读SQL。包含同名21人、10/10/1分页、准确匹配、字面通配符、SQL注入字符串、缺条件、不同门店、已封存门店、非老师角色、跨客户工单／照片拦截、非本人备注／留言写入拒绝，以及自己的客户保留写权。无生产数据写入。
- 原生微信开发者工具：320/390宽手机、768/834/1024宽iPad；查询、门店模糊选择、10条表格、下一页、完整客户主页只读按钮和充值工单链接已检查。补齐430与横屏记录以最终发布回执为准。
