# 本人月历／总部老师主页：考勤地图补齐

## 修改

- 两处页面的上下班详情此前没有 `<map>`，只有文字地址及打开地图按钮；不是地图权限或水印版本导致。
- 两处均用保存的打卡经纬度显示地图和位置标记。文字地址为空仍可预览；有地址才显示文字，不再堆叠“未解析附近地点／暂无文字地址”。
- 共用小程序内展示辅助函数校验坐标：空白、null、非数字、非有限值、越界值不转为 0；真实 0 坐标仍合法。缺失坐标不显示假地图或可点击位置按钮。
- 手机先原图后地图；700px 起地图／照片等宽两列，底部按钮对齐。原图组件、缓存、照片获取与水印不变。
- 没有定位采集、人脸、核销、BLE、扣次、权限、数据库、云函数或 Web 变更；不补写历史坐标／地址。

## 验证

- 全仓串行 539 项通过；新增 6 项检查覆盖两处页面、上下班坐标、无文字地址、非法／缺失坐标、历史位置打开与响应式布局。原有体验充值防重复与异步竞争测试仍执行，只给测试装载器添加新展示模块依赖。
- 原生开发者工具使用公开地点合成坐标、现有品牌图片代替私人照片，仅内存态预览；业务网络请求被阻止，未写测试打卡、未持久化伪身份、未修改权限或生产数据。新页面实际编译、地图瓦片／标记及上下班区域可见。
- 手机 320／390／430px：两处页面地图宽度分别为 265／324／358px（本人）和 267／318／351px（总部），均在屏内；窄屏和现代刘海屏可滚动到下班地图及按钮。
- iPad 768×1024：两处左右栏均为 314px；834×1112 均为 347px；1024×1366 均为 442px，位置和照片栏总高均为 292px，查看按钮同底线。1024×768 横屏首轮检查保持两列。大屏缺坐标与未打卡状态已实际显示，前者没有地图或位置按钮，后者不构造地图。
- 调试期间切换设备会重启脚本上下文；重启前注入的临时调试函数失效错误不作为产品故障。早期快速重复创建调试页面出现一次渲染层 shadowRoot 错误；重新编译并单次初始化后页面正常，后续尺寸检查无同类复现。没有将合成调试数据或脚本加入小程序源码。
