# 2026-11-05 小程序门店、项目与产品名称展示检查

用户要求全面清理门店、项目和实物产品编码，包含办理页及产品查询。按全部 46 份 WXML、69 份自有 JavaScript 检查可见文本、下拉标签、资料映射、工单事实、弹窗和成功反馈，更新 PROJECT_CONTEXT 中旧编号展示规则。仅修改微信小程序；数据库、共享接口和网页版未改。

| 范围 | 检查与处理 |
| --- | --- |
| 老师七项办理 | 共用门店搜索结果去掉编码；七项页的兼容标签也只用名称。保留模糊搜索、明确点选及原门店 ID。 |
| 充值、退费、产品购买 | 项目和实物产品选择只显示名称；可退／剩余次数及赠品件数保留。赠品草稿不显示产品码。 |
| 客户、充值、核销及产品查询 | 门店筛选只用名称，产品查询去掉产品名后拼接的代码，封存状态仍可辨认。查询结果原有名称、来源、件数、工单号与分页保留。 |
| 审核与运营 | 审核、余次预警、未核销预警的门店标签去掉代码；评价分析、考勤／日报追踪原本无此编码展示。 |
| 主页与客户资料 | 门店主页／总部门店详情去掉业务编号，客户资料所属门店只显示名称；总部排名、老师业务、客户名单和项目汇总原本只显示名称。 |
| 工单与导出 | 去掉门店事实下方代码、充值赠品下方产品代码；保留客户身份、真实工单号和导出既有名称／数量。购买详情原本只有产品和门店名称。 |
| 管理与反馈 | 产品管理删除编号列，手机改为三列，平板删除对应空行；长名称可换行。封存／激活确认及新增成功提示也不拼接产品编码，兼容旧创建回执。项目及门店管理原本使用名称。 |
| 公司介绍、导航与共用组件 | 检查公开项目介绍、菜单、项目汇总与老师业务组件，无额外门店／产品／项目代码展示。客户编号、序号及真实工单号不属于本轮移除范围。 |

标识完整保留在内部模型、路由、请求参数和历史快照；不按名字替代唯一 ID。运行时测试用同名门店、同名产品确认第二项仍提交精确原 ID；管理确认弹窗隐藏代码后，状态操作仍提交原 productRef。产品查询全部来源／全部状态适配不变。只做展示精简，不改任何核销创建、审核、扣次、人脸、照片、BLE 或账号权限。

`node --test --test-concurrency=4 tests/*.test.js`：685 项通过。包括客户、补录、核销、防重、审核、照片、BLE 与角色隔离既有回归；旧测试中要求显示产品码／业务编号的断言按用户新决定更新。增加全模板可见字段检查以及同名对象身份、旧创建回执与管理操作的运行时检查。

原生隔离项目使用 112 份逐字节一致的生产源文件，替换 API／会话／上传队列／CloudBase 初始化为本地合成读取；主页初始化用合成资料替代。无 SDK 登录、照片采集或云端写入。390 手机检查产品查询及其产品下拉，管理、客户资料、充值工单、门店主页／详情、六个查询／审核／预警入口与七项办理门店展开结果；320／430 手机复核产品表格长名称、状态与按钮。iPad 768、834、1024 竖屏及 1024×768 横屏检查卡片和门店结果。
