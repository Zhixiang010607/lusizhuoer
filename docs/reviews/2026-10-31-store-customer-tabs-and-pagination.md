# 门店客户名单切换与底部分页验收

## 范围与决定

仅修改小程序门店主页及总部进入的门店详情。活跃／封存用户合并为一张客户名单卡，两个等宽按钮切换，默认活跃。切换只更新本地展示，不更改客户状态、不额外请求接口；各自的分页数据、输入及原读取权限保留。

手机底部拆为两组：上一页／当前页码／下一页；跳至第／输入／页／跳转。700px 及以上平板同排居中，控件等高，短文字不折行。沿用每页十条、每页从 1 开始的序号、末页收缩与表格内部仅横向滚动；输入后键盘完成也能跳页。首页原来两份名单锚点合并为客户名单。正常／体验／补录核销、扣次、照片、BLE、权限、数据库、云函数和 legacy Web 均未修改。

本轮按手机、平板与跨端 UI 技能要求使用局部样式、暖色按钮、手机分组／平板物理像素同排布局，并在原生开发者工具中复核。

## 边界与交付状态

这是受影响名单的隔离原生验收，不是全站／所有路由验收，也不替代真实手机、iPad 微信客户端的上线后检查。空名单保留原有空态，未逐尺寸重做原生空态验收。开发者工具 3.17.1 基础库在反复切换设备期间曾出现框架层警告／错误，不能据此声称全程控制台零错误；重新加载后的列表与分页交互可完成，本轮未为消除工具噪声修改业务逻辑。

本轮无 SQL、云函数或静态 Web 发布。源码提交推送与小程序上传／体验版／正式发布是不同状态；本轮尚未上传小程序。
