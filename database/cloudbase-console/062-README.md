# 062 产品购买工单

执行顺序：

1. 先确认 060、061 已执行并验收。
2. 整文件复制执行 `062-01-retail-product-purchases.sql`。
3. 整文件复制执行 `062-readonly-verify.sql`；结果表会一次显示五行，五项均应为 `READY`。
4. 再上传 `faceRecognition-v94.zip` 与 `staffAccount-v75.zip`。

062 新增独立产品购买工单。门店和老师可以为所属门店的活跃客户提交；老师由当前登录 UID 自动绑定本人，门店提交不指定老师。总部只能审核，不能提交。只有审核通过的数量才计入客户主页“产品汇总”的“购买”；已通过充值单的赠品计入“赠送”。购买与赠送都不改变项目次数、核销、体验额度或库存。
