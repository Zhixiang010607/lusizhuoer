# Migration 061

本迁移把充值申请中的可选实物／涂抹类产品赠予保存为独立、不可变的工单明细：

- 只允许绑定 `NEW` 充值单，退费单不能带赠品；
- 每行绑定同一充值单、客户、门店以及该单最终确定的业务老师；门店未选老师时允许为空；
- 提交时产品必须仍为 `ACTIVE`，并固化产品编号、名称快照与正整数数量；
- 同一充值单内同一产品只出现一次，最多 20 种，每种 1—999 件；
- 前端提交前可以删除清单项；写入工单后的赠品明细禁止更新或删除；
- 产品后来封存不会抹除历史赠品，不创建库存、余额或项目次数。

1. `061-01-recharge-product-gifts.sql`；
2. `061-readonly-verify.sql`（只读）。

只读验证必须返回 8 行，且每一行 `status` 都是 `READY`。之后再上传本轮 `faceRecognition` 与 `staffAccount` 云函数 ZIP。
