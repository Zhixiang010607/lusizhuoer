# 086 培训学习 PDF

本迁移新增私有培训资料表。总部账号可以上传、发布和删除（下架）PDF；在职老师只能读取已发布资料；门店账号没有入口，服务端也拒绝访问。删除仅改变状态，不物理删除文件或记录；当前不提供重新发布入口。文件本体保存在独立私有存储桶，数据库只保存私有引用和元数据。

执行顺序：

1. 完成并验收迁移 085；
2. 整文件执行 `086-01-training-materials.sql`；
3. 迁移会幂等创建或收紧私有桶 `training-materials`：100 MiB、仅允许 `application/pdf`，不得给 `anon` 或 `authenticated` 增加整桶策略；
4. 执行 `086-readonly-verify.sql`，五行必须全部返回 `READY`；
5. 上传并验收 `staffAccount-v93.zip`；
6. 上传配套小程序开发版并以总部、老师、门店三个账号分别验收。

老师端不显示下载按钮，打开 PDF 时关闭微信文档菜单，也不调用永久保存接口。微信仍需把加密授权后的文件传到临时文件中才能交给原生 PDF 阅读器；应用不会把该临时文件保存到用户文件区。
