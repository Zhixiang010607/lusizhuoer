# 064 可选择核销次数

本迁移把正常核销和老师体验核销从固定 `1` 次改为办理人员必须选择的
`1—999` 次，并在同一事务中按所选次数校验、扣减和写入设备信号来源记录。

执行顺序：

1. 确认迁移 063 已完成且其两份只读验收全部为 `READY`。
2. 在短暂停止核销写入的窗口，完整执行
   `064-01-variable-verification-unit-count.sql`。
3. 立即上传 `faceRecognition-v98.zip`；旧 v97 在迁移后会明确拒绝核销，
   不会继续按固定 1 次写入。
4. 调用 `faceRecognition` 的 `health`，确认返回 `version=v98`。
5. 执行 `064-readonly-verify.sql`，8 行必须全部为 `record_count=0`、
   `status=READY`。
6. 再发布本提交中的网页和小程序，并分别用正常核销、体验核销验证
   多次扣减、余额／额度不足、重复提交和超时恢复。

迁移失败时事务会整体回滚。不要重跑旧的 041、054 或 056 函数文件覆盖
064；不要在只升级前端而尚未执行 064、上传 v98 的情况下开放核销。
