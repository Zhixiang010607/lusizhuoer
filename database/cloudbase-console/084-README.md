# 084 日报单栏 1000 字

本迁移把老师日报的最终写入规则调整为只填写“今日完成事项”，必填且最多 1000 个 Unicode 字符。PostgreSQL `TEXT` 保留 UTF-8 内容，因此 emoji、鼓掌等特殊符号可以正常保存。

执行顺序：

1. 整文件执行 `084-01-daily-report-single-field-1000-characters.sql`；
2. 执行 `084-readonly-verify.sql`，三行必须全部返回 `READY`；
3. 继续执行并验收迁移 085；
4. 上传并验收 `staffAccount-v92.zip`；
5. 发布配套网页并上传配套小程序。

迁移不批量改写历史日报。历史四栏内容继续保留并可由兼容接口读取；迁移后的新增和当天修改只保存“今日完成事项”，另外三列写为空字符串以兼容现有表结构。历史日期仍不可修改，日报仍不可删除，总部仍只有只读权限。
