# 094：总部审核短信接收设置

任何在职总部账号均可修改任意总部账号的接收设置，默认不接收；老师、门店和封存账号无管理权限。设置以总部账号为单位，覆盖产品、充值、退费、补录核销四类审核。封存人员不可开启接收。设置持久化不代表短信已启用：模板、签名及实际发送服务尚待上线，当前不发送短信。

顺序：

1. 只读执行 [094-preview.sql](094-preview.sql)，确认目标环境与 migration_already_present=false；已执行时不重复迁移。
2. 通过 scripts/cloudbase-pg-change.js 的完整备份门禁执行 [094-01-hq-review-sms-preferences.sql](094-01-hq-review-sms-preferences.sql)，不得直接绕过备份写生产。
3. 独立执行 [094-readonly-verify.sql](094-readonly-verify.sql)，五项 READY。新表应为空，原业务表、序列与备份相同。
4. 部署 staffAccount v103，核对 health、全部根文件回下载，再发布总部 Web。无需重传其他云函数。小程序导出修复独立发布，无新服务端依赖。

本迁移不创建短信模板、不发送测试短信，不改审核、充值、退费、核销和余额。保留最新设置、更新人及时间，不创建历史业务记录。实际生产状态以部署回执为准。

最终四项独立选择以095为准，094仅为前置。首次上线按094、095顺序分别经备份门禁；部署staffAccount v104。已完成094不重跑。
