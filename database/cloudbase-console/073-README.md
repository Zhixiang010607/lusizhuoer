# 073 老师工作日报

本迁移建立老师个人日报。只有在职老师账号能通过云函数写入、修改和查看自己的日报；总部不能代写，门店和非在职老师不能访问。每名老师每个上海业务日期最多一份。总部只读追踪由后续迁移 074 和独立总部接口提供。

## 当前规则

- 只能新增或修改上海时间的当天日报；
- 历史日报永久只读，未来日期不能填写；
- 老师不能删除日报，也不能把日报改到另一日期或另一账号；
- 客户端不能直接访问日报表，必须由按当前 CloudBase UID 鉴权的 `staffAccount` 云函数办理；
- “今日完成事项”必填，四个文本字段每项最多 2000 字符。

## 执行顺序

1. 整文件执行 `073-01-staff-daily-reports.sql`；
2. 整文件执行 `073-readonly-verify.sql`；
3. 确认 7 行全部为 `READY`，且 `record_count` 全部为 `0`；
4. 上传 `deployments/staffAccount-v83.zip`；
5. 调用 `{ "action": "health" }`，确认 `version=v83`；
6. 继续执行迁移 074，再发布新增日报页面和更新后的 `auth-ui.js`。

必须先执行数据库迁移，再部署云函数和网页。数据库结构缺失时，日报接口会关闭并提示执行迁移 073、074。
