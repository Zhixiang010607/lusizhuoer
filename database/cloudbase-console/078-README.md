# 078 老师每日上班／下班两次打卡

1. 完整执行 `078-01-teacher-two-punch-attendance.sql`。
2. 执行 `078-readonly-verify.sql`，五行结果必须全部为 `READY`。
3. 再部署 `faceRecognition v124`、`staffAccount v86`，最后上传配套小程序。

既有考勤记录全部保留，并自动视为“上班打卡”。迁移后每位老师每个上海业务日最多各有一笔不可修改、不可删除的上班和下班记录；下班记录必须在同日上班记录已经成功写入后才能产生。现场照片仍只用于当次质量、活体和 1:1 人脸验证，不会保存。
