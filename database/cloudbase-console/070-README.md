# 070 扫码评价固定三项评分

按以下顺序在生产 CloudBase PostgreSQL 环境执行：

1. 整文件执行 `070-01-rating-always-three-scores.sql`。
2. 整文件执行 `070-readonly-verify.sql`，5 行必须全部返回 `READY`。
3. 部署 `customerRating v8`。
4. 发布当前 `rating.html` 与 `rating.js`，并用未指定业务老师的真实工单二维码确认第 02 项“老师服务”仍显示且必填。

迁移只增加评价表单版本，并把所有新评价固定为三项评分。既有已经提交且没有业务老师评分的历史 v1 评价保持原样，不伪造分数；所有新建或尚未提交的二维码在 v8 页面提交时都必须包含门店环境、老师服务和整体体验三项 1-5 星。
