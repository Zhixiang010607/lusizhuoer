## 本版内容

- 保持 LASER-BLE 精简 JSON 报文和字段完全不变。
- 连接后读取实际 ATT MTU；Android 请求 MTU 185，iOS 使用系统与 HC-08 自动协商并由微信回读的值。
- 单次有效载荷取 `MTU - 3`，实现上限 182 字节；MTU 不可读、无效或为 23 时安全回退 20 字节。
- 约 76—77 字节的精简授权在实际 MTU 至少 79—80 时可以一次写完，否则继续按协商上限顺序分片。
- 写入失败诊断增加实际 MTU 和单包上限，但不显示报文、设备编号、nonce、签名或 token。
- 大包授权写入结果不确定时不会自动改成小包重发；仍先补查真实状态，或同设备重新扫码取得新 token。
- 同一张有效资格只允许重扫同一二维码和同一设备；待机时服务端覆盖签发新 token，旧 token 立即失效；工作态只恢复原工单。

## 设备端要求

设备继续接收 UTF-8 JSON + LF。设备必须把 GATT 写入当作连续字节流：既能处理一次写入完整 JSON，也能缓存多次写入直到 LF 后再解析；不得假定授权固定为 4 片。当前设备端实施说明为 [`../../output/pdf/Lusizhuoer_BLE_Device_Interaction_Protocol_V4.0.pdf`](../../output/pdf/Lusizhuoer_BLE_Device_Interaction_Protocol_V4.0.pdf)。
