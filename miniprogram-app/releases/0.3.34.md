# 小程序开发版 0.3.34

日期：2026-10-12（Australia/Sydney）

## 修复与边界

- 包含已上传开发版 0.3.33 的原始门店上下文和 PDF 持久上传恢复修复。
- 培训资料搜索与文件列表分为两个独立卡片；文件名、上传任务标题和资料标题调大一档，长名称截断但不挤占操作按钮。
- 阅读、删除、重新选择 PDF、上传及重试按钮显式居中并限制宽度；长错误文本自动换行，重试按钮保留独立列。
- 后台列表不再把已经 COMMITTED 的任务误显示为“等待上传”；立即重试仍使用原任务编号，不重复选择、创建或发布资料。
- 老师“学习”下拉项复用“办理”的菜单样式，根据实际按钮与窗口几何出现在自身下方；页面隐藏、旋转及晚到的测量回调不能重新打开旧菜单。
- 门店与老师入口“补录核销申请”精简为“补录核销”，SUPPLEMENT/PENDING、总部审核通过后才扣次的语义不变。
- 共享 `staffAccount v94` 仅修复 PDF 相对签名地址兼容；私有桶、角色权限、五分钟签名和 100 MiB 上传上限保留。不改数据库、核销服务、设备通信或扣次规则。
