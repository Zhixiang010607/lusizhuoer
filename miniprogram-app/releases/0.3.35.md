# 小程序开发版 0.3.35

日期：2026-10-12（Australia/Sydney）

## 修复

- PDF 上传进度分为准备、传输、校验发布和恢复原请求，展示当前阶段真实等待时间。当前签名 PUT 不支持原生字节进度回调，不伪造百分比；传输成功回执之后才显示实际已传字节。
- 失败任务单独显示，使用原任务编号重试，确认后可以移除；未确认成功不混入资料列表。服务器仍禁止删除已绑定资料的私有对象。修复移除任务被旧队列快照重新加入、已完成任务冷启动残留、发布回执丢失但本地 PDF 已不在的恢复问题。
- 已耗尽重试次数的任务不因进入页面再次自动开始新一轮。失败错误按准备、签名、传输、发布区分，签名地址不进入本地失败提示。
- 老师／总部每次阅读先向服务端重新校验权限和资料状态，再复用私有缓存；首次读取显示真实下载进度。下载文件字节不完整时禁止打开，坏缓存失效并只补读一次；缓存存储不可用时仅允许回退到已校验完整的临时文件。
- 页面卸载或账号切换不能让旧异步响应打开 PDF。仍使用原生全屏阅读和 `showMenu: false`，不新增老师上传、删除、保存或转发入口。
- 失败任务按钮限定独立列且双向居中，移除使用弱红语义；上传禁用按钮使用显式状态类，避免原生浅灰文字覆盖造成不可读。搜索与文件列表继续分框。
