# 小程序开发版 0.3.25

日期：2026-10-11

## 本版内容

- 延续 `0.3.22`—`0.3.24` 的字号统一：总部数据范围、完整排名、打卡／日报追踪、产品／门店／老师管理，以及老师／门店首页业务汇总、业务明细和用户表，手机与 iPad 分别使用统一的表头和数据字号；项目汇总在总部、门店、老师三端使用相同模板，项目名称居中且不显示内部编号。
- 门店和老师管理查询区的标签、输入内容、占位文字与按钮字号调大到和其他查询页一致。
- 老师日报最终只保留“今日完成事项”，必填、最多 1000 个 Unicode 字符，支持 emoji 和其他特殊符号；网页版与小程序的录入、追踪、个人月历详情采用同一规则。
- 项目单据模板页面的返回入口固定在标题右上角并增加清晰边框，页面整体字号调大；核销单说明和充值单说明分别最多 1000 个 Unicode 字符，手动换行原样保存与显示，自然折行不会写入额外换行，支持 emoji 和其他特殊符号。
- 项目 LOGO 操作精简为两个等宽等高按钮：“选择或替换图片”和“移除图片”。选择后立即通过既有私有签名直传自动上传保存，读取继续走鉴权分块接口，不增加公开桶或第三个保存按钮。
- 正常核销、体验核销、补录核销、核销照片、BLE、设备授权、余额复核和扣次规则均未修改。
