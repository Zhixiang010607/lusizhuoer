# 小程序开发版 0.3.21

日期：2026-10-10

## 本版内容

- 核销完成后的三个补充照片位，服务端单张硬上限由 3 MiB 提升为 5 MiB。
- 从相册选择的原图或微信相机已经生成的 JPEG 不超过 5 MiB 时保留完整现有字节，不缩像素、不二次编码。
- 超过 5 MiB 时使用微信原生 `wx.compressImage` 按完整画面等比压缩，目标不超过 4.5 MiB；逐级降低质量和最长边，但禁止裁切。
- 压缩后回读真实宽高并校验画面比例；横图、竖图和 EXIF 方向照片使用同一安全规则。
- 选择后立即本地预览、持久化上传队列、离开页面继续上传、重启恢复和三个补充照片位保持不变。

## 服务端依赖

1. 在生产数据库执行迁移 083，并确认五项只读检查全部为 `READY`。
2. 部署 `faceRecognition v128`。
3. 部署 `verificationPhoto v13`，确认共享实现为 `v12`。
4. 私有照片桶的单文件限制必须至少为 5 MiB，并继续只允许 JPEG。

迁移 083 不修改 `FACE` 现场人脸证据的 3 MiB 上限，也不改变正常／体验／补录核销、人脸、BLE、余额和扣次规则。
