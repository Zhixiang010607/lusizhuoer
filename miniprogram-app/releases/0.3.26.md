# 小程序开发版 0.3.26

日期：2026-10-11

## 本版内容

- 核销凭证缩小客户、项目、次数等信息字号，压缩信息卡高度、间距和留白，避免姓名与数据突兀放大；正常核销、体验核销和补录核销的业务逻辑、照片、BLE、余额复核和扣次均未修改。
- 正常核销的项目模板预览增加二维码版式示例，并明确标注“不可扫码”；正式工单仍只接受服务端签发的真实 PNG 二维码，不允许本地伪造二维码进入正式导出。
- 项目单据模板页不再显示内部项目编号和重复帮助文字；两段说明输入区显著增高，继续分别限制 1000 个 Unicode 字符并原样保留手动换行、emoji 和特殊符号。
- 项目 LOGO 操作保留“选择或替换图片／移除图片”两个等宽按钮，降低按钮视觉强调度；上传和读取继续使用既有私有签名直传和鉴权读取，不改公开状态。
- 老师项目配置继续使用紧凑表格并隐藏内部项目编号；总部、门店、老师三端的项目汇总继续使用相同模板和居中项目名称。
- 日报继续只保留“今日完成事项”，必填且最多 1000 个 Unicode 字符，手动换行与 emoji 原样保存和显示。
